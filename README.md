
# HyperLocal Service Connect

A web application that connects customers with local service providers.

## Project Goals

- Allow customers to discover local service providers.
- Enable customers to book services.
- Allow workers to manage booking requests.
- Provide a secure and user-friendly experience.

## Technology Stack

- Node.js
- Express.js
- MongoDB
- React
- Git and GitHub
- Jira
- Hoppscotch

## Project Status

Development setup in progress.
